# Пиццерия "La pizza di Don Corleone"

Веб-приложение для онлайн-заказа пиццы, напитков и десертов. Разработано на ASP.NET Core 8 + Blazor Server с использованием Entity Framework Core (SQLite), MudBlazor и Docker.

## Функциональность

- Каталог товаров (пиццы, напитки, десерты) с фильтрацией по названию/описанию и вегетарианским пиццам.
- Корзина с добавлением, удалением, изменением количества, сохранением между обновлениями страницы.
- Оформление заказа с выбором способа получения (доставка по Москве или самовывоз), валидацией телефона и адреса.
- Панель администратора (`/admin/orders`) с фильтрацией заказов по статусу, дате, поиском по телефону/ID, статистикой (сегодня/вчера/всего).
- Страница "Мои заказы" (`/my-orders`) – просмотр заказов по номеру телефона.
- Docker-контейнеризация (multi-stage build, том для SQLite).

## Технологии

- .NET 8
- Blazor Server
- Entity Framework Core (Code First)
- SQLite
- MudBlazor / Bootstrap (страница оформления заказа и админка на чистом Bootstrap)
- Docker

## Запуск через .NET SDK (локально)

1. Установите [.NET 8 SDK](https://dotnet.microsoft.com/download).
2. Склонируйте репозиторий:  
   `git clone <URL_репозитория>`
3. Перейдите в папку проекта:  
   `cd BlazorPizzeria`
4. Восстановите пакеты:  
   `dotnet restore`
5. Примените миграции базы данных:  
   `dotnet ef database update`
6. Запустите приложение:  
   `dotnet run`
7. Откройте браузер и перейдите по адресу `https://localhost:xxx`.

## Запуск через Docker

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Скачайте файл docker-compose.yml из проекта.
3. Выполните команду:
   `docker-compose up -d`
4. Откройте браузер и перейдите по адресу `http://localhost:8020`.


## Структура проекта

- `Models/` – сущности базы данных.
- `Data/` – DbContext и конфигурация.
- `Services/` – репозитории, сервис корзины.
- `Components/` – Blazor-компоненты и страницы.
- `Validators/` – FluentValidation валидаторы.
- `wwwroot/` – статические файлы (картинки, стили).
